# Finals-GroupProject-Website

## BusinessPro Solutions - A Business Consulting Website

This is a group project website focused on the business topic. It features a professional business consulting company website with multiple pages and modern design.

### Features

- **Home Page**: Welcoming hero section with key features and benefits
- **About Us Page**: Team member profiles and company mission/values
- **Services Page**: Comprehensive list of business services offered
- **Contact Page**: Contact form and business information
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Professional Styling**: Modern gradient designs and clean interface

### Pages

1. **index.html** - Homepage with hero section and feature highlights
2. **about.html** - About us page with team member information
3. **services.html** - Detailed services offerings
4. **contact.html** - Contact form and business contact information

### Technologies Used

- HTML5
- CSS3 (with responsive design)
- Modern gradient backgrounds
- Clean, professional typography

### How to View

Simply open `index.html` in a web browser to view the website. All pages are linked through the navigation menu.

### Project Info

This website showcases business consulting services and demonstrates web development skills including:
- Multi-page website structure
- Responsive design principles
- Professional business website layout
- Navigation between pages
- Contact form implementation
